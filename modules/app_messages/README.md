# «Сообщения» (app_messages) для MajorDoMo

Мессенджер терминалов и пользователей MajorDoMo: страница **/popup/app_messages.html**, приложение в списке приложений.

Модуль вынесен из полной версии «Терминалов» ([artt652/majordomo-terminals](https://github.com/artt652/majordomo-terminals), ветка `main`). Сами «Терминалы» — ветка `alpha` того же репозитория — отвечают только за доставку на устройства (очередь, дополнения).

## Что умеет

- Чаты: «Все терминалы», комнаты MajorDoMo, свои группы, личные чаты терминалов и пользователей, общий чат MajorDoMo (shoutbox) и его комнаты.
- Текст (с озвучкой на устройстве или без), фото, видео, музыка, файлы, голосовые.
- Галочки: отправлено, доставлено (устройство приняло), прочитано.
- Вход на странице: по ключу терминала (ссылка, QR-код) или из панели управления; ключи пользователей. Из панели — от пользователя, без терминала (все терминалы, в том числе MAIN, — обычные чаты); терминал — если выбрать его под стрелкой у имени. Сообщения из панели подписаны «Имя (из панели управления)». «Только по ключу» включено у всех терминалов по умолчанию; выключить у терминала — вход и как прежде (адрес, сессия, `?terminal=`).
- Камеры go2rtc: чат «Камеры», показ на терминалах, снимки, временный доступ и гостевые ссылки. **Временно здесь** — переедут в отдельный модуль go2rtc.
- Вебсокет (событие `TERMINAL_MESSAGE`), опрос — запасной вариант.

Вложения хранятся в `cms/cached/terminals` (как раньше — старые сообщения на них ссылаются), журнал — `cms/debmes/<дата>/app_messages.log`.

## Настройки (панель управления → «Сообщения»)

- **Настройки:** адрес вебсокета для внешнего доступа, срок хранения истории, ключи пользователей.
- **Терминалы:** у каждого терминала — ключ доступа к странице (ссылка, QR-код, пример API), «Только по ключу», «Пересоздать», сообщение на терминал, экран устройства (если дополнение умеет `screenState()` / `screen()`). Раньше это были вкладки в карточке терминала.
- **Камеры (go2rtc):** адрес и пароль API go2rtc, адрес для устройств, RTSP, WebTorrent, ожидание первого кадра; права на камеры.

## Для сценариев

```php
include_once(DIR_MODULES . 'app_messages/app_messages.class.php');
messagesSend('Кухня', 'Ужин готов', array('from' => 'Гостиная', 'image' => 'cms/cached/snapshot.jpg'));
```

Все параметры — в начале `messages_send.inc.php`. Прежнее имя `terminalsSend()` работает (если его не объявил кто-то ещё).

## Связь с «Терминалами»

- **Новые «Терминалы»** (константа `TERMINALS_API`, ветка `alpha`): сообщения идут через очередь устройства; картинку и отправителя показывает дополнение с `showMessage()`; каждая запись уходит с меткой `app_messages:<номер>`, и по событию `TERMINAL_DELIVERED` ставится «доставлено». Переименование и удаление терминала — события `TERMINAL_RENAMED` / `TERMINAL_DELETED` (группы, аватарки, ключи).
- **Прежние «Терминалы»** (upstream): работает урезанно — на устройство уходит только текст (`terminalSay` / `SAYTO`), звук и видео — методами дополнения напрямую; «доставлено» ставится, когда сообщение отдано «Терминалам». Переименование терминала группы не узнают. В настройках — предупреждение.

## Установка и переход с полной версии «Терминалов»

Скопировать файлы поверх MajorDoMo и установить модуль. Создаются таблицы `messages_history`, `messages_groups`, `messages_colors`, `messages_tokens` и подписки на `MINUTELY`, `TERMINAL_DELIVERED`, `TERMINAL_RENAMED`, `TERMINAL_DELETED`.

Если раньше стояла полная версия «Терминалов» (ветка `main`), при установке один раз переносятся:
- переписка, группы, аватарки и ключи — из `terminals_messages`, `terminals_groups`, `terminals_colors`, `terminals_tokens` (только в пустые таблицы);
- настройки «Сообщений» и камер — из конфигурации модуля «Терминалы» (`MESSAGES_*`, `GO2RTC_*`, `CAMERA_ACCESS`).

Прежние таблицы не удаляются — после проверки их можно удалить вручную. Ссылки и QR-коды на устройствах не меняются: адрес страницы и ключи те же.

Совместимо с PHP 7 и 8.
